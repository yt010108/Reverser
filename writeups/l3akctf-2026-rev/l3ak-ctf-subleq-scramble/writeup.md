## 분석 요약
1. **에뮬레이터 작성**: 표준 subleq 세맨틱(`mem[b] -= mem[a]`, 결과 ≤0이면 pc=c), 포트 규약 `a==-1` 입력 / `b==-1` 출력(하위 8비트), pc<0이면 정지.
2. **프로그램 구조**
   - 워드 195–214: `"Ant out of bounds:\n "` (음수화 ASCII) — 실행 중 실제 출력되는 배너
   - 워드 216–250: 숨겨진 문자열(아래 참조) — 코드 어디서도 참조되지 않는 dead data
   - 워드 264–3455: 84×38 비트 격자(주소 = 264 + 84*r + c, 값 0/1)
   - 코드는 셀 90/97/136을 연산 슬롯으로 재기록하는 자기수정 간접 주소 사용. 개미(Langton's Ant 변형) 시뮬레이션이며 즉시 경계 이탈로 종료.
3. **격자 복호화 시도**(모두 구조 없음 확인): 행 순환 시프트 DP, shear, 아핀 순열 전수, 2D 자기상관, 레이아웃 후보, 반복 실행 등.
4. **플래그 획득**: 워드 216–250의 음수화 ASCII를 양전위로 디코딩.
