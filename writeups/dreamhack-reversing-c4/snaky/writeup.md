# Snaky — Dreamhack Reversing C4 (amd64 ELF)

## 결과
- 상태: solved (로컬 검증 완료, `good :)` 확인)
- 플래그 후보: 수락된 이동 문자열 106자 (ctf_record_flag로 저장, 실제 값은 `.private` 상태에만 기록)
- 참고: 바이너리는 "good :)"만 출력하므로 플래그는 플랫폼에서 이 입력값(또는 DH{} 래핑)으로 인정되는 것으로 추정

## 바이너리 요약
- stripped ELF64, No PIE(0x400000), scanf("%255s")로 문자열 입력
- 문자셋 검증(0x40127a): {K, 9, z, 7, 2, s} 외의 문자(NUL 제외)면 실패
- 3D 그리드(25×25×25, base 0x404060, index = x + 25y + 625z) 위 뱀 시뮬레이션(0x401348)
  - 시작 (24,12,12), 도달 목표 (0,12,12)면 성공(1 반환)
  - 이동: K=x+1, 9=x-1, z=y+1, 7=y-1, 2=z+1, s=z-1  ← 주의: s/7 역할이 직관과 반대
  - 각 이동 후 범위(0..24) 검사 및 방문/벽 검사(셀 값==1이면 실패) 후 mark(=1)
- .data의 grid는 **1로 채워진 미로**(자유 셀 107개)로 초기화되어 있어 단순 직진 경로는 불가

## 풀이
1. objdump -s -j .data로 15625바이트 grid 추출 → 자유 셀(값≠1) 107개
2. 첫 DFS 시도는 s/7 축 매핑을 잘못 읽어 실패 → gdb로 이동별 좌표 추적(0x401435 bp)해 매핑 확정
3. 올바른 매핑으로 DFS(self-avoiding path): 시작→목표 106수 경로 발견(모든 자유 셀 방문, 해밀토니안 경로)
4. 동적 검증: 해당 문자열 입력 시 "good :)" 출력
